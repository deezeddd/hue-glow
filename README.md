# Hue Glow

A colour picker that glows. One screen: the colour rises from the bottom, its name sits large in the corner, and the hex, RGB and HSL values copy with a tap. Drag the bar at the bottom or anywhere on the screen. Arrow keys nudge by one, shift for ten. The link carries the hue, so `#h300` opens on purple.

Single static file, no build, no dependencies beyond two Google Fonts. Works on phones and desktops.
