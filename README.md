# Hue Glow

A colour picker that glows. One screen: the colour rises from the bottom, its name sits large in the corner, and the hex, RGB and HSL values copy with a tap.

Three controls, all in the same dark glass: a hue bar and a saturation bar along the bottom, a lightness bar standing at the right. Drag anywhere on the screen to move hue and lightness together. Arrow keys nudge by one, shift for ten.

Names come from the open colour name list. Five thousand of the best names ship with the page, and the full list of about 32,000 loads quietly afterwards, so every point in the wheel gets the closest named colour.

The link carries all three values, so `#h20s70l72` opens on the same peach.

Two static files, no build. Works on phones and desktops.
